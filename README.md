Entry for the [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d) bounty on make.fun.

`main.py` writes one funny line to `/output/entry.txt`:

> I lit up for nobody four times tonight. I'm not a nightlight, I'm a stage, and you're bombing.

The fridge has lit its light for an empty kitchen four times tonight and has had enough: it is not a nightlight, it is a stage, and the owner is bombing. The punchline lands on the last two words — the appliance has decided 3AM is the moment to speak, and it is roasting its owner.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
